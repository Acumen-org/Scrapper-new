# Bellwether runtime dependencies. Deliberately small.
#
# No pandas (streaming CSV and iterparse handle files larger than memory),
# no pypdf (pdfplumber is the one that actually extracts these layouts),
# and no LLM or enrichment API client anywhere: every derived value in this
# system has to trace back to a filing, which rules them out by design.
#
# Versions are the ones this has actually been run and QA-gated against, read
# from the working environment rather than chosen from release notes.

uvicorn==0.41.0

# absent here while still present in the Windows environment, which is exactly
# why it went unnoticed until the image was run.
